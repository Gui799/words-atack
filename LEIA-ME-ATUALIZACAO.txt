ATUALIZAÇÃO DO JOGO — WORDS ATACK 0.2.0

Esta revisão altera a tela do jogo para 640 x 360 (exibição 1280 x 720), muda
o cenário para o dia e integra a nova interface e os spritesheets animados.

Arquivos principais alterados/adicionados:
- game/main.py, game/settings.py e game/rendering.py
- game/assets/ (cenário, interface, cursor, vidas, inimigo e efeitos)
- scripts/build_windows.py (inclui as artes ao gerar o executável)
- GUIA-PIXEL-ART.md (dimensões e grades para LibreSprite)

Para atualizar seu clone, copie os arquivos do projeto preservando
docs/config.js, confira as alterações no GitHub Desktop e faça commit/push.
Não publique o executável antigo como se já contivesse esta revisão. Para
gerar um novo pacote Windows, execute no Windows com os requisitos instalados:

    python scripts/build_windows.py

A pasta de arte agora usa uma base lógica 640 x 360. Consulte GUIA-PIXEL-ART.md
antes de desenhar novos elementos ou substituir os spritesheets.
